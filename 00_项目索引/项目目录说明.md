# 三指灵巧手与珞石机器人项目目录

本目录的主程序是通过珞石机器人控制器与机器人末端 485 接口通信，控制 DexHand021 S 三指灵巧手的可视化界面。

## 目录分类

| 目录 | 内容 | 是否作为程序上传 |
|---|---|---|
| `ROKAE_xMate_SDK` | 珞石 xCore SDK、Python 控制界面、机器人示例和 SDK 资料 | 是 |
| `02_灵巧手SDK` | DexHand C++ SDK、DexRobot SDK 及相关模型/接口源码 | 是，按需使用 |
| `03_协议与设备资料` | 末端透传手册、DexHand 使用说明、RS485 示例和珞石资料 | 是，保留说明资料 |
| `04_实验与采集` | D435i、眼在手标定、实验脚本和采集数据 | 是，按需使用 |
| `90_本地运行产物_不上传` | 日志、缓存、测试输出、临时 RL 工程和文档渲染结果 | 否 |
| `99_本地归档_不上传` | ZIP、TAR.GZ 等压缩归档包 | 否 |
| `venv` | 当前电脑的 Python 运行环境 | 否 |

## 主控制界面运行

在本目录打开 PowerShell：

```powershell
Set-Location "C:\Users\sxy18\Desktop\记录留痕\20260810三指灵巧手"
& ".\venv\Scripts\python.exe" ".\ROKAE_xMate_SDK\xCoreSDK-Python\gui\robot_control_gui.py"
```

主界面选择“机器人末端 485（珞石控制器透传）”时，电脑不打开 COM 口；电脑通过网线连接机器人控制器，由珞石 SDK 发送末端 485 数据。DexHand021 S 的设备 ID、115200、8N1 和 Modbus RTU 帧仍按灵巧手说明书执行。

## 目录整理原则

- `ROKAE_xMate_SDK` 和主控制界面的原始相对路径保持不变，现有运行命令无需修改。
- 本地虚拟环境、缓存、日志、临时工程和压缩包不作为源代码，不上传 GitHub。
- 以后新增的实验数据放入 `04_实验与采集`；新增手册或协议放入 `03_协议与设备资料`。
